# Chat tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Settings tab with a Chat tab that holds your log as one kept thread, with Settings behind a gear and one bar system across the tabs.

**Architecture:** A small persisted Zustand store (`stores/chatStore.ts`) holds thread items; producers (`useLogDraft.save`, `usePlanner.planIt`, `useCoach`) append to it. Pure helpers (`services/thread.ts`, `services/opener.ts`, `askChips`) decide what's sent, drawn and suggested, and are unit-tested under node. The Chat tab renders the store and reuses `ChatScreen`, `ParsedCard`, `FoodCard`, `PlanCard` and `CoachCard`.

**Tech Stack:** Expo Router, React Native, Zustand persist + AsyncStorage, node:test via tsx.

**Spec:** `docs/superpowers/specs/2026-10-15-chat-tab-design.md`

## Global Constraints

- OTA only: no new native modules or dependencies.
- Storage key: `@training-tracker/chat`, kept forever, included in backups.
- Coach unchanged (Worker, prompt, pack, guards). Coach thread context: today's last 6 question/answer pairs.
- Opener, chips, cards and charts make no AI calls.
- Copy: "the last 7 days", never "this week"; no exclamation marks. Placeholder on Chat: "Log something or ask".
- Gear on Chat only. Ask pill and `app/ask.tsx` removed.

## Review Focus

- A `logged` item whose workouts and food were all deleted → card reads "Deleted", no crash, Open hidden.
- Restoring a backup made before this change (no chat key) → restore succeeds, thread empty.
- A question that names two lifts or none → no chart (never a wrong chart).
- Yesterday's answers in the store → not sent back with today's question.
- "Clear all data" → thread is empty too.

Each has a test in the task that owns it (Tasks 1, 2, 4).

### Task 2: Opener and ask chips

**Files:**
- Create: `services/opener.ts`, `services/opener.test.mts`
- Modify: `services/suggestions.ts`, `services/suggestions.test.mts`

**Interfaces:**
- Produces:
  - `type Opener = { kind: 'planned'; templateId: string; name: string; note?: string } | { kind: 'comeback'; days: number } | { kind: 'welcome' } | null`
  - `pickOpener(input: { workouts: Workout[]; schedule: TemplateSchedule[]; templates: WorkoutTemplate[]; library: ExerciseLibrary; unit: WeightUnit; threadEmpty: boolean; skippedOpener?: string }, now: Date): Opener`
  - `askChips(workouts: Workout[], library: ExerciseLibrary, unit: WeightUnit, proteinGoal: boolean): Chip[]`
  - `openerText(o: Opener): string` exact copy: planned → `${name} is planned for today.`; comeback → `${days} days since your last workout. Start with whatever has rested longest.`; welcome → `Tell me what you did or ate, or ask about your training.`
- Rules, first wins: (1) a schedule entry for today, not completed or skipped, with an existing template, no workout logged today, `skippedOpener !== today` → planned; `note` = "<Group> hasn't been trained in the last 7 days." for the first of the template's muscle groups with `daysSinceGroupTrained` ≥ 7 or missing (capitalized); (2) `digest.daysSinceLastWorkout >= 5` and `usualPerWeek !== null` → comeback; (3) `threadEmpty` → welcome; else null.
- `askChips`: with workouts: `Is my <first word of most-logged lift with numbers, lowercase> stuck?` (only if a lift trend exists), `What should I train tomorrow?`, and `How's my protein?` when `proteinGoal`. No workouts: the old Ask `STARTERS` (moved here, exported as `ASK_STARTERS`).

- [ ] **Step 1: Tests** — one per rule, rule order (planned beats comeback), skipped today hides planned, a schedule entry whose template is gone falls through, chips for names-only (no "stuck" chip), numbered, and new users.
- [ ] **Step 2: fail → Step 3: implement → Step 4: pass. Commit.**

### Task 3: Producers write to the thread

**Files:**
- Modify: `hooks/useLogDraft.ts` (in `save`), `hooks/usePlanner.ts` (in `planIt`), `hooks/useCoach.ts`

**Interfaces:**
- Consumes: `useChatStore` (Task 1), `coachThread`, `chartFor`.
- `useLogDraft.save`: after adding, `add({kind:'you', text: sent})` when `sent` is set, then `add({kind:'logged', workoutIds, foodEntryIds, day: date})`.
- `usePlanner.planIt`: after save, `add({kind:'you', text: messages[0]})`, `add({kind:'planned', dates})` with the dates of schedule entries whose `planId === plan.id`.
- `useCoach()` returns `{ text, setText, pending: string | null, busy, error, ask, plan(id, workout), logMeal(id, meal, k), remember(id, yes), chips }`. `ask` keeps the question in `pending` while thinking; on success adds `you` + `answer` (with `chartExerciseId = chartFor(question, digest.liftTrends)`); on error restores the text. Thread sent = `coachThread(items, now)`. `plan/logMeal/remember` patch the stored answer by id. `MAX_TURNS` and `startOver` go. `chips` = the newest answer's chips if it's the last item.

- [ ] **Step 1:** Implement; `npx tsc --noEmit` clean. Commit.
